# Windows服务器：窗口关闭后的继续步骤

仅在你已远程连接的Windows服务器内操作。脚本窗口关闭并不能说明安装成功。常见原因是独立窗口执行后退出、缺少PackagePath参数、执行策略阻止、Node下载失败，或上次解压后旧脚本拒绝重试。新版支持保留数据和配置后重新运行，并显示5步进度。

1. 下载最新 zhuzhuan-aliyun.zip，将它复制到服务器 C:\Deploy\zhuzhuan-aliyun.zip（新建C:\Deploy文件夹）。右键压缩包“全部解压缩”，选择 C:\Deploy\zhuzhuan-files。确认里面存在 deploy\windows\Initialize-Windows.ps1。
2. 在服务器开始菜单搜索“Windows PowerShell”，右键“以管理员身份运行”。不要双击ps1，不要使用会自动退出的独立运行窗口。
3. 在这个已经打开的窗口粘贴：

```powershell
Test-Path 'C:\Deploy\zhuzhuan-aliyun.zip'
Test-Path 'C:\Deploy\zhuzhuan-files\deploy\windows\Initialize-Windows.ps1'
```

两项都应显示True。False说明文件位置不同，先按实际位置修改路径。

4. 在同一个窗口运行（开头的&不可省略，PackagePath指向zip而不是ps1）：

```powershell
& 'C:\Deploy\zhuzhuan-files\deploy\windows\Initialize-Windows.ps1' -PackagePath 'C:\Deploy\zhuzhuan-aliyun.zip'
```

会显示[1/5]至[5/5]进度，以及v24.x版本。下载可能需数分钟。窗口应保持打开，红色错误会留在窗口里。若提示无法加载脚本或未签名，先运行Get-ExecutionPolicy -List，将错误和策略结果反馈，不要直接全局禁用策略。

5. 成功后运行：

```powershell
Test-Path 'C:\Zhuzhuan\tools\node.exe'
Test-Path 'C:\Zhuzhuan\app\server\main.mjs'
Test-Path 'C:\Zhuzhuan\config\server.env'
notepad 'C:\Zhuzhuan\config\server.env'
```

前三项应True。只在服务器记事本里填入高德凭据，不发聊天，不改变HOST=127.0.0.1或测试APP_ORIGIN=http://localhost:8788。

6. 保存配置后运行：

```powershell
& 'C:\Zhuzhuan\app\deploy\windows\Start-Website.ps1'
```

命令保持运行是正常现象。在服务器的浏览器打开 http://localhost:8788。不要在你自己的电脑浏览器输入这个地址来验证服务器。若打不开，再开一个PowerShell窗口，运行Get-Content 'C:\Zhuzhuan\logs\website-日期.log' -Tail 30（日期替换实际文件名；可先Get-ChildItem 'C:\Zhuzhuan\logs'）。只反馈错误文字，勿复制私有server.env。

7. 本地页面和功能验证成功后再安装自动启动任务及HTTPS。此阶段不开放公网8788、不修改DNS。杭州正式公网发布仍待备案。
